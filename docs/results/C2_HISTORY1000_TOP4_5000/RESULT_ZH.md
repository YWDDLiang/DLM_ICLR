# 历史面板＋F800高SUN组：5000条合并结果

历史1050条中的原顺序前1000条，随后按以下顺序接入新面板：原第2001–3000条、原第3001–4000条、原第4001–5000条、原第1001–2000条。
新增组依据已测F800 SUN选取，并列时按原顺序选择，因此本表是结果引导选定面板的描述性比较。
历史及已完成的一次修订C2端点在输入结构和种子核对一致后复用；其余请求运行相同C2。每个比较组都按合并顺序重算UN，不相加旧表的Unique或SUN。
F先评价，已确认SUN保留；回退版仅对原MSUN编辑失去确认SUN/MSUN时恢复F。两版都使用物理标签。
