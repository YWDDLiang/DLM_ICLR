# F800 与 SUN 保护 C2：SUN／MSUN／VUN 统一结果

本文件保留历史面板的共同已知 1005 条报告，并在文末追加合并 3000 条实验。两个面板分别统计，不混用分母。

从同一组 1050 条原请求中，剔除任一比较组的 Stable、Meta Stable、SUN、MSUN、comp_valid、struct_valid、V、U、N、VUN 存在未知的请求；共剔除 45 条，保留共同 **1005 条**。以下所有统计表均使用这一相同子集和分母。

**已确认失败保留在分母。Unique 沿用完整原始请求顺序的判定，不在去未知子集内重新计算。结果是共同已知子集上的统计，不等同于原全量成功率。**

**comp_valid=SMACT 3.1 原规则通过，或同一氧化态表下混合价态补充通过。** V=comp_valid∧struct_valid；VUN=V∧U∧N。SUN/MSUN沿用固定物理协议，不额外乘组成有效性。

**Stable：终态通过固定物理检查且 E_hull≤0；Meta Stable：终态通过固定物理检查且 E_hull≤0.1 eV/atom，包含 Stable。** 这两列不要求 Unique 或 Novel；属于冻结 CHGNet＋hull 协议下的预测结果。物理终态无效计为未通过。

两种保护／回退方案均为使用真实物理标签的消融；复用冻结 F800 和保留的一次修订 C2。

## 保护／回退规则

- 两版均保留原 F 端已确认 SUN 的输出。
- 回退版：仅 MSUN 的请求仍进行编辑；编辑结果确认达到 SUN/MSUN 才接受，否则回到 F。
- 不回退版：同样进行编辑，保留一次修订 C2 的最终选择，不按编辑后的真实 MSUN 标签额外回退。
- 去未知只改变报告子集，没有重新运行或重新选择任何结构。
