# C2: geometry-conditioned editing and one conditional revision

C2 receives the continuous F output and its token view. Fixed source geometry and the evolving proposal geometry condition the DLM's embeddings. Candidate actions open coordinate blocks; masked conditional filling proposes new token values. Continuous patching changes only fields whose tokens changed, preserving the remaining F geometry.

An independent value model compares each candidate to the same current structure:

$$\Delta v(c)=v(S,c)-v(S,S),\qquad J_0(c)=2\Delta v_{NS}(c)+\Delta v_{NMS}(c).$$

KEEP has exactly zero relative value. The default candidate budget is eight proposals and at most 80 logical DLM forwards. Local proposals can cover 1, 2, 4 or 8 sites; whole-coordinate and cell modes are also available.

Training consists of crystal reconstruction warm-up, physical feedback collection, supervised editor fitting, a small physical-teacher update and value fitting using the final editor's features. The light update mixes original targets with a finite-candidate reward-weighted teacher at fraction 0.25 and temperature 0.1. It runs for one epoch at LoRA LR `1e-6` after the eight-epoch editor stage.

One additional revision inspects up to three changed fields of a completed single-site candidate. The same DLM predicts each masked field using the completed surrounding context. A learned contact-risk model tilts the conditional probabilities:

$$q_\lambda(k)\propto p_\theta(k)\exp[-\lambda\widehat r(k)].$$

The tilt uses strength at most 2 with KL budget 0.1. A single revised candidate joins the current structure and the original winner. Selection subtracts relative predicted risk with weight 0.5. The reference profile uses minimum predicted risk reduction `0.18866579450426538`.

The default pipeline evaluates F first and preserves confirmed SUN structures. Other requests use C2's learned selection. Final physical results are evaluated after selection.

```bash
bash scripts/train.sh c2 --config configs/local.json
bash scripts/sample.sh c2 --config configs/local.json
```

The implementation uses these ideas within the retained crystal editor.
