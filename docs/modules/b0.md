# B0: crystal vocabulary warm-up

B0 adapts LLaDA to a dynamic sequence of length `7 + 4N`: atom count, six lattice parameters, then one element and three fractional coordinates per atom. Material conditions remain visible while randomly selected answer tokens are masked.

The loss averages masked-token cross-entropy over each answer and weights it by inverse masking probability. Both input embeddings and output vocabulary tables are trained alongside LoRA, allowing the new crystal tokens to acquire meaning.

Defaults: two epochs, effective batch 16, LR `5e-5`, cosine schedule, warm-up 100, minimum LR ratio 0.2, LoRA rank 8/alpha 32/dropout 0.05 on `q_proj`, `k_proj`, `v_proj`, `ff_proj`, `up_proj`. Maximum length is derived from prepared data. Single- and dual-process execution use the same effective batch.

```bash
bash scripts/train.sh b0 --config configs/local.json
```

Code: [objective](../../src/dlm_iclr/b0/objective.py), [trainer](../../src/dlm_iclr/b0/trainer.py). Background: [Large Language Diffusion Models](https://arxiv.org/abs/2502.09992), [masked diffusion](https://arxiv.org/abs/2406.07524), [LoRA](https://openreview.net/forum?id=nZeVKeeFYf9).
