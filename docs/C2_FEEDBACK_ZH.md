# 注册 draft-feedback 配方：DLM 与固定 C1 的协作

本文是 `python -m dlm_iclr.feedback` 独立配方的简明入口，完整定义见[注册教师与前缀反馈方法](C1_C2_METHOD_ZH.md)。原 KEEP/EDIT 的故事、数学与教师机制见[物理反馈 Master Story](PHYSICAL_FEEDBACK_MASTER_STORY_ZH.md)。对应研究分支为 `codex/verified-feedback-train-20260920`；两条参数更新路径及其结果分别保留。

当前方法的主线是：**Planner 条件 → DLM+C1 构造 raw → 冻结连续 diffusion 与物理工具提出、核验更好的结构 → C2 整理几何教师与真实前缀监督 → 学习回 DLM → 继续通过 C1 构造 draft。**

该配方目标是把外部精修经验转化为首次生成器的能力。它已得到限定的小规模已见 TRAIN 证据；扩大的 raw 对照没有复现该原生收益，结果见[完整 raw 报告](results/reporting-1306-raw.md)。这不改变原 KEEP/EDIT 主实验的模型或证据。

## 三个模块分别负责什么

| 模块 | 当前职责 | 与其他模块的联系 |
|---|---|---|
| DLM | 在原 prompt 与可见几何条件下预测晶格、坐标 token，并输出 hidden states | 给 C1 提供位置分数与上下文表示；接受 C2 构造的监督 |
| C1 | 用晶格条件和周期相互作用，把坐标位置分数组织成当前轴的联合分布 | 每次提交后重新读取 DLM 上下文，影响后续坐标构造 |
| C2 反馈机制 | 借助连续候选和物理工具，产生可以学习的完整教师、相容前缀目标与质量权重 | 保留同一 Plan/prompt，把外部改善变成 DLM 的训练样本 |

C1 已有的周期几何建模与结构有效性贡献继续保留。周期相容性本身不等于低能量、低力或热力学稳定，因此还需要 C2 的物理反馈学习。当前发挥作用的 C2 是监督构造与核验机制，不应描述成已经证明有效的 learned 在线 verifier。

## C2 把什么交给 DLM 学习

**第一类是完整几何教师。** 冻结的 diffusion 及允许的物理弛豫产生晶格和坐标候选。候选经过精确 token 量化、解码与重新测量，才能作为离散模型的目标。连续结构好，不代表量化后的结构仍然好，故不能直接沿用父结构的物理分数。

周期平移、同元素原子重排可能让同一个晶体表现为不同 token 序列。完整教师因此只作整数 bin 的全局周期平移和同元素置换，保留教师晶格与相对几何，再核验新 token 结构。这样减少与物理内容无关的表示差异，而不是要求 DLM 去学习任意坐标原点。

完整教师的训练包含晶格阶段和 XYZ 阶段。预测晶格时，未来坐标被遮住；晶格与坐标作为相容的整体目标学习。

**第二类是真实构造前缀监督。** 读取 C1 曾经实际使用的 prompt、学生晶格、可见坐标和提交位置。保持全部可见内容，借助教师提出缺失坐标的补全。这个组合只是候选，必须再次物理核验；不能因为教师本身好，就假定它适合任意学生晶格或前缀。

当前核心监督使用同条件的已知原生质量评分 `raw_utility` 正增量，采样权重为 `gain / (1 + gain)`。增益比较的是“完整补全结构”与“产生这条前缀的原始完整 raw”。评分包含力、应力和相对 hull 的能量项。未达到 SUN/MSUN、但相对质量改善的结构也可用于学习。其他字段的改善与取舍保留在记录中，未知不伪造为负例。

前缀样本先按来源与轴平衡，再在相应池内按正增益权重抽样；抽到后不再额外乘一次该权重。监督仅覆盖原来的实际提交位置，整个补全的其余缺失坐标用于物理核验。完整教师与前缀样本以 75/25 的固定 microbatch 周期混合，优化有类型约束的 token 平均负对数概率。具体定义见[实际训练目标](C1_C2_METHOD_ZH.md#learning)。

这个增量属于完整补全结构，不能说成单个提交动作的独立因果收益。当前损失是带类型约束的 token 重构代理，不是完整 C1 构造轨迹的精确 DPO。

## C2 怎样影响 C1 下一次生成的位置

设 DLM 参数为 `theta`，C1 周期头参数为 `psi`。构造时，C1 使用 DLM 的位置分数、hidden states、当前晶格和已知坐标建立分布 `q(theta, psi)`。

C2 的教师与前缀监督把 DLM 更新为 `theta_plus`。下一次生成中，C1 接收更新后的分数和 hidden states，构造的是 `q(theta_plus, psi)`。因此，**C2 先通过学习改变 DLM 的预测，再由 C1 把这些预测组织成周期相容的坐标选择。**

当前取得 TRAIN 证据的配方只更新 DLM LoRA，固定 C1 参数。C1 参数固定不代表它每次输出固定，因为其输入来自已经改变的 DLM。当前也没有把晶格和全部 XYZ 同时当作一个精确联合分布求解；C1 的精确树推断作用于当前坐标轴。

如果未来加入 C1 再适配或 learned 在线候选选择，需要单独实证，不能把未生效的研究分支算入本配方的贡献。

## 训练与推理的边界

训练数据构造允许使用 CHGNet、物理弛豫与 hull 参考。当前没有从 F 或 CHGNet 向 DLM 直接反向传播；连续模型提供几何候选，连续物理量帮助核验和赋权，随后由离散训练目标更新参数。也没有宣称蒸馏了整个 diffusion 轨迹。

推理时，模型依据自己的参数、原 prompt 和已经生成的内容构造 raw。它不能检索训练教师、读取真实候选物理标签或未来 F 结果来决定本次生成。物理评价发生在生成之后。C2 不再编辑 F 输出。

物理工具可以只评价完整结构，但教师配对、前缀监督与 DLM 训练必须绑定同一个 Plan/prompt，不能把坐标当成脱离条件的答案。

## 当前训练与 F400 对照

已验证的小规模配方为 75% 完整注册教师、25% 核验前缀监督，LoRA 学习率 1e-5，micro batch 4、effective batch 8，C1 固定。截至 2026-09-20 本次文档更新，原 H1A2 1050 + R03 256 请求的扩大训练已完成 6656 步，使用 1244 个完整教师和 3747 个前缀视图。训练更新量按条件和几何阶段覆盖扩展；这些汇报数据转作 TRAIN 后不能称为独立测试。

扩大训练的 teacher NLL 为 4.81624→3.70280、固定前缀 NLL 为 5.53935→3.51846，坐标 top-1 仍只有 11.6%。随后完成的 raw 配对没有复现原生稳定改善：严格代理两侧均为 1/1306，平均原生能量和力 RMS 变差；F800/F400 尚未完成，评价与后续研究将在本次提交后暂停讨论。见[扩大 raw 结果与诊断](results/reporting-1306-raw.md)。扩大评价的 before 是 model25 起点，不是论文原始 B0。

当前对两个模型比较 **raw、F800、F400**：同一批 Plan、原 prompt、body 温度 0.2、原始随机种子及物理协议。每个模型只生成一份 raw，F400 和 F800 都从这份 raw 出发。还会比较学生 F400 与训练前模型 F800，并报告实际精修耗时。

源码中 `time_start = diff_steps`，所以 F400 同时改变起始时间与步数，并非直接截断同一条 F800 轨迹。只有真实质量与成本对照出来后，才能判断是否获得精修效率收益；目前不预先宣称减半无损。

原生单点稳定代理、常规 raw SUN/MSUN（包含既定 CHGNet 弛豫终态标签）、F 端点结果分别报告。保持原物理阈值、失败和未知分母，联合面板与子面板分别计算 Unique。现有小 TRAIN 的原生稳定代理 7/64→35/64 是限定条件下的结果，不等于未见 MP-20 泛化、DFT 验证或 learned 在线 critic 已成功。
